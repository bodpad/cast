---
description: Show cast browser profiles (people Claude can act as in the browser)
allowed-tools: mcp__plugin_cast_cast__cast_list
---

Call `cast_list` and show the profiles as a compact list: name, scope, email, description, sites, and whether each is open now. For profiles that are not ready, say the user can set them up with `/cast:add <name>`. If there are none, suggest `/cast:add <name>`.
